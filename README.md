# 📈 โปรแกรมวิเคราะห์หุ้นไทย (Thai Stock Analysis System)

โปรแกรมนี้ถูกออกแบบมาเพื่อช่วยนักลงทุนวิเคราะห์หุ้นไทยโดยใช้หลักการ **"Value & Growth Investing"** โดยดึงข้อมูลสดจากตลาดหลักทรัพย์ผ่าน Yahoo Finance และจัดทำ Dashboard วิเคราะห์ความคุ้มค่าให้โดยอัตโนมัติ

---

## 🛠 วิธีการติดตั้งและเริ่มใช้งาน

### 1. การเตรียมความพร้อม (ครั้งแรกเท่านั้น)
*   **ติดตั้ง Python**: ดาวน์โหลดได้ที่ [python.org](https://www.python.org/)
*   **ติดตั้งโปรแกรมเสริม**: เปิด Terminal หรือ Command Prompt ในโฟลเดอร์ของโปรแกรม แล้วพิมพ์คำสั่ง:
    ```bash
    pip install -r requirements.txt
    ```

### 2. การเตรียมข้อมูลของคุณ
*   **ไฟล์พอร์ตหุ้น (Portfolio)**: ใช้ไฟล์ Excel (เช่น `portfolio.xlsx`) โดยต้องมีหัวข้อคอลัมน์ดังนี้:
    *   `Symbol`: ชื่อหุ้น (เช่น PTT, CPALL)
    *   `Quantity`: จำนวนหุ้นที่มี
    *   `Avg_Price`: ราคาต้นทุนเฉลี่ย
*   **ไฟล์หุ้นที่สนใจ (Watchlist)**: ใช้ไฟล์ Text (เช่น `watchlist.txt`) พิมพ์ชื่อหุ้นบรรทัดละ 1 ชื่อ

### 3. การรันโปรแกรมวิเคราะห์ (สร้างรายงาน)
พิมพ์คำสั่งใน Terminal:
```bash
python main.py
```
จากนั้นระบบจะดึงข้อมูลสดและสร้างไฟล์รายงาน Excel และรูปภาพ Dashboard สรุปผล

### 4. การรัน Interactive Dashboard (วิเคราะห์และคัดกรองหุ้น)
หากคุณต้องการวิเคราะห์พอร์ตแบบละเอียด หรือค้นหาหุ้นใหม่ๆ ให้พิมพ์คำสั่ง:
```bash
streamlit run portfolio_dashboard.py
```
Dashboard ประกอบด้วย 3 โหมดหลัก:
1.  **วิเคราะห์พอร์ต**: ดูผลตอบแทนและระดับความเสี่ยงของหุ้นที่มีอยู่
2.  **คัดกรองหุ้น (Screener)**: ค้นหาหุ้น "เพชรในตม" จาก Watchlist ด้วยตัวกรอง Score, D/E, ROE และ RSI
3.  **วิเคราะห์กลุ่มอุตสาหกรรม (Sector)**: เปรียบเทียบหุ้นตัวหนึ่งกับค่าเฉลี่ยของกลุ่ม (Benchmark) เพื่อหาผู้ชนะในกลุ่มนั้น

## 🧠 หลักการวิเคราะห์และคำนวณคะแนน (Scoring Logic)

ระบบเวอร์ชันปัจจุบันใช้การวิเคราะห์แบบ **Hybrid (Fundamental + Technical + Relative)**:

### 1. ปัจจัยความปลอดภัยและความคุ้มค่า (Fundamental - 50%)
*   **D/E Ratio (20%)**: ให้คะแนนสูงกับหุ้นหนี้ต่ำ (< 1.0) หากหนี้สูงเกิน 2.5 จะโดนหักคะแนนความน่าสนใจทันที
*   **PE & ROE (30%)**: วัดความถูกแพงเทียบกับกำไร และประสิทธิภาพการบริหารงาน

### 2. ปัจจัยจังหวะเวลา (Timing & Technical - 20%)
*   **Price Position (10%)**: ราคายิ่งใกล้จุดต่ำสุดรอบปี ยิ่งได้คะแนนสูง (Discount)
*   **RSI Indicator (10%)**: ให้คะแนนพิเศษเมื่อ RSI < 35 (Oversold) เพื่อชี้จุดกลับตัว

### 3. การวิเคราะห์เชิงเปรียบเทียบ (Sector-Relative - 30%) **[ใหม่!]**
*   **Sector Benchmarking**: ระบบจะคำนวณค่าเฉลี่ย PE และ ROE ของแต่ละกลุ่มอุตสาหกรรมโดยอัตโนมัติ
*   **Relative Bonus**: หุ้นที่ **"เก่งกว่ากลุ่ม"** (ROE สูงกว่าเฉลี่ย) และ **"ถูกกว่ากลุ่ม"** (PE ต่ำกว่าเฉลี่ย) จะได้คะแนนโบนัสเพิ่มขึ้น เพื่อให้การเปรียบเทียบมีความยุติธรรมตามลักษณะธุรกิจ

## 💡 วิธีการตีความสถานะและเกณฑ์ตัดสินใจ
สามารถดูคู่มือฉบับย่อได้ในแถบ **"คลิกดูเกณฑ์ตัดสินใจ"** ที่ด้านซ้ายของหน้า Dashboard ซึ่งสรุปเกณฑ์มาตรฐานที่นักลงทุนมืออาชีพใช้ไว้อย่างครบถ้วน

ในหน้าจอวิเคราะห์ Watchlist จะมีข้อมูลเพิ่มเติมดังนี้:
*   **Price Status**: 💎 ถูกมาก, 🟢 ราคาถูก, 🟡 กลางๆ, 🟠 เริ่มแพง, 🔴 แพง
*   **Technical Status**:
    *   **💎 จุดกลับตัว (Oversold)**: RSI ต่ำกว่า 30 (โอกาสทองในการเข้าซื้อ)
    *   **🔥 ร้อนแรง (Overbought)**: RSI สูงกว่า 70 (ควรระวัง หรือพิจารณาขายทำกำไร)
    *   **⚖️ ปกติ**: RSI อยู่ในช่วง 30-70

## 📊 คู่มือการอ่านกราฟ Dashboard (วิธีวิเคราะห์เพื่อลงทุน)

เมื่อโปรแกรมทำงานเสร็จ จะสร้างไฟล์รูปภาพ `stock_analysis_dashboard.png` ซึ่งประกอบด้วย 4 กราฟหลัก ดังนี้:

### กราฟที่ 1: หุ้นแนะนำ 10 อันดับแรก
*   **ดูอย่างไร**: ยิ่งแท่งกราฟยาว คะแนน (Total Score) ยิ่งสูง
*   **วิเคราะห์**: หุ้นกลุ่มนี้คือหุ้นที่ "สอบผ่าน" ทุกเกณฑ์ ทั้งราคาถูก ปันผลดี และกำไรเติบโตเด่น เป็นกลุ่มแรกที่ควรพิจารณาเข้าลงทุน

### กราฟที่ 2: ความสัมพันธ์ราคา (PE) vs ปันผล (Yield) **[สำคัญที่สุด]**
*   **แกนนอน (PE)**: ยิ่งอยู่ **ซ้าย** ยิ่งดี (แปลว่าหุ้นราคาถูกเมื่อเทียบกับกำไร)
*   **แกนตั้ง (Yield)**: ยิ่งอยู่ **บน** ยิ่งดี (แปลว่าให้เงินปันผลตอบแทนสูง)
*   **ขนาดของจุด (ROE)**: ยิ่งจุด **ใหญ่** ยิ่งดี (แปลว่าบริษัทใช้เงินทุนสร้างกำไรได้เก่ง)
*   **สรุป**: มองหาหุ้นที่อยู่ใน **"โซนน่าสนใจที่สุด" (กล่องสีเขียวซ้ายบน)** หุ้นเหล่านี้คือ "ของถูกและดี" ที่หาได้ยากในตลาด

### กราฟที่ 3: การกระจายคะแนนหุ้นในตลาด
*   **วิธีดูสุขภาพตลาด**:
    *   **แท่งกราฟกองอยู่ฝั่งขวา (คะแนนสูงเยอะ)**: ตลาดช่วงนั้น "ถูกและดี" น่าลงทุนที่สุด
    *   **แท่งกราฟกองอยู่ฝั่งซ้าย (คะแนนต่ำเยอะ)**: หุ้นในตลาดเริ่มแพง หรือกำไรไม่ดี ควรใช้ความระมัดระวัง

### กราฟที่ 4: ตารางความสัมพันธ์ (Correlation)
*   **วิเคราะห์ความสอดคล้อง**: ช่วยยืนยันว่าหุ้นที่ได้คะแนนสูง สัมพันธ์กับปัจจัยไหนมากที่สุด (เช่น ส่วนใหญ่มักสัมพันธ์กับ ROE หรือ Yield)

## 📂 รายละเอียดไฟล์ในโปรเจกต์
1.  **`main.py`**: หัวใจหลักของโปรแกรม ทำหน้าที่เชื่อมโยงทุกส่วนและสร้างรายงาน
2.  **`stock_scraper.py`**: ดึงข้อมูลราคาหุ้นสด, ราคา High/Low รอบ 1 ปี และคำนวณ RSI
3.  **`stock_analyzer.py`**: วิเคราะห์พื้นฐานธุรกิจร่วมกับเทคนิคราคา และคำนวณคะแนน (Total Score)
4.  **`stock_visualizer.py`**: ออกแบบ Dashboard สรุปภาพรวมตลาดในรูปแบบรูปภาพ
5.  **`[Portfolio_Name]_analysis_report.xlsx`**: **รายงานฉบับสมบูรณ์** (ประกอบด้วย 2 แผ่นงาน):
    *   **Portfolio Analysis**: รายละเอียดพอร์ต พร้อมระบบระบายสี **เขียว-เหลือง-แดง** ในช่องราคา เพื่อบอกความถูกแพง และคำแนะนำรายตัว
    *   **How to Read**: คู่มืออธิบายความหมายของค่าต่างๆ และเกณฑ์การวิเคราะห์สำหรับมือใหม่

## 📈 วิธีวิเคราะห์เพื่อการตัดสินใจ (Quick Guide)
1.  **มองหาสีเขียวใน Excel**: คือหุ้นที่ราคาลงมาต่ำมากในรอบปี (Discount)
2.  **เช็คสัญญาณ RSI**: หาก RSI < 30 (Oversold) คือจุดกลับตัวที่น่าซื้อที่สุด
3.  **ดู Total Score**: หุ้นที่ได้คะแนน > 70 คือหุ้นที่พื้นฐานแกร่งและราคาคุ้มค่า
4.  **ทำตาม Advice**: ระบบจะแนะนำ "ซื้อเพิ่ม", "ถือต่อ" หรือ "ขาย" ตามสถานการณ์จริงของหุ้นและต้นทุนของคุณ
